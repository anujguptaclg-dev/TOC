How Grammar String Derivation Works

Theory of Computation • Regular Grammars & Bounded BFS Search

Execution Workflow

  1. 1. Enter a regular grammar: Specify non-terminals, terminals, and right-linear productions of the form A → aB, A → a, or A → ε.
  2. 2. Enter the target string: Provide the word $w \in \Sigma^*$ you wish to test (e.g. ab, or empty string ε).
  3. 3. Set maximum derivation steps N: Restrict the search depth to at most $N$ production applications.
  4. 4. Start from the start symbol: BFS begins exploration with the sentential form equal to the designated start variable (e.g. $S$).
  5. 5. Explore possible derivations: At every step, the algorithm replaces the leftmost non-terminal using all applicable production rules, generating all valid successor sentential forms.
  6. 6. Termination conditions: The search halts immediately when:
    • The target string is generated (shortest derivation found via BFS), OR
    • All search branches either reach the $N$-step limit, dead-end, or are pruned due to terminal prefix mismatch.
  7. 7. Derivation tree visualization: The resulting state-space tree shows every explored branch, highlights the winning derivation path in emerald green, and flags pruned branches.

Key Concepts

Regular Grammar

A regular grammar is a formal grammar whose productions are restricted to right-linear ($A \to aB \mid a \mid \varepsilon$) or left-linear ($A \to Ba \mid a \mid \varepsilon$) forms. It generates exactly the class of regular languages recognized by Finite Automata (DFA/NFA).

Derivation & Sentential Form

A derivation is a sequence of rule applications $S \Rightarrow \alpha_1 \Rightarrow \alpha_2 \dots \Rightarrow w$. Any intermediate string $\alpha_i \in (V \cup \Sigma)^*$ containing non-terminals is called a sentential form.

N-Step Limit & BFS

Because grammars can contain recursive rules (e.g. $S \to aS$) that create infinite derivation paths, Breadth-First Search (BFS) combined with an $N$-step bound guarantees shortest derivation discovery and terminates safely.

Prefix Pruning

In right-linear grammars, generated terminals form a prefix that can never be undone. If the terminal prefix of a sentential form does not match the target string's prefix, the branch is safely pruned without missing any valid derivation.
